## 环境要求

| 工具 | 最低版本 | 说明 |
|------|----------|------|
| Node.js | >= 18 | 前端构建 |
| Rust | 最新 stable | 通过 [rustup](https://rustup.rs/) 安装 |
| Windows | 10+ | 需 Visual Studio Build Tools（C++ 桌面开发） |
| macOS | 11+ | 需 Xcode Command Line Tools |
| Linux | — | 需 `libwebkit2gtk-4.1-dev` `libgtk-3-dev` 等 |

安装 Rust 工具链：

```bash
rustup install stable
rustup target add wasm32-unknown-unknown  # 可选，WebAssembly 目标
```

Linux 额外依赖（Debian/Ubuntu）：

```bash
sudo apt install libwebkit2gtk-4.1-dev libgtk-3-dev \
  libayatana-appindicator3-dev librsvg2-dev \
  libasound2-dev libssl-dev
```

## 开发

### 安装依赖

```bash
npm install
```

### 启动开发模式

```bash
npm run tauri dev
```

执行流程：
1. `tauri dev` 启动 Rust 后端编译（debug 模式）
2. 同时启动 Vite 开发服务器（`localhost:1420`）
3. Tauri WebView 加载 Vite dev server 页面
4. 前端修改触发热更新（HMR），Rust 修改触发重新编译

### 仅前端开发

```bash
npm run dev        # 启动 Vite，浏览器访问 localhost:1420
```

注意：脱离 Tauri 运行时，所有 `@tauri-apps/api` 调用会失败。

### Rust 类型检查

```bash
cd src-tauri
cargo check       # 仅检查，不生成二进制
cargo clippy      # Lint 检查
```

## 构建

### 前端构建

```bash
npm run build      # 等价于 tsc -b && vite build
```

步骤：
1. `tsc -b` — TypeScript 类型检查，生成 `tsconfig.tsbuildinfo`
2. `vite build` — Rollup 打包，输出到 `dist/`

Vite 构建会生成两个入口产物：
- `dist/index.html` → 主窗口
- `dist/src/marquee/marquee.html` → 滚动字幕窗口

### Tauri 构建（完整打包）

```bash
npm run tauri build
```

执行流程：
1. 运行 `beforeBuildCommand` — `npm run build`
2. 编译 Rust 源码（release 模式，`--release`）
3. 将 `dist/` 嵌入 Tauri WebView
4. 根据 `bundle` 配置生成平台安装包

产物路径：`src-tauri/target/release/bundle/`

| 平台 | 产物 |
|------|------|
| Windows | `.msi` / `.nsis.exe` |
| macOS | `.dmg` / `.app` |
| Linux | `.deb` / `.rpm` / `.AppImage` |

### 一键构建脚本（Windows）

根目录的 `build-release.bat` 封装了完整构建环境初始化：

```bat
@echo off
set PATH=%USERPROFILE%\.cargo\bin;%PATH%
call "...VsDevCmd.bat" -arch=x64 -host_arch=x64
npm run tauri build
```

适合在未配置 Rust/MSVC 环境变量的终端中直接双击运行。

### 构建参数

```bash
# 仅编译二进制（不生成安装包）
npm run tauri build -- --bundles none

# 指定目标平台（需交叉编译环境）
npm run tauri build -- --target x86_64-pc-windows-msvc

# Debug 构建
npm run tauri build -- --debug

# 指定安装包格式
npm run tauri build -- --bundles msi        # 仅 MSI
npm run tauri build -- --bundles deb,appimage  # Linux 多格式
```

### 交叉编译

Windows 上编译 Linux 目标：

```bash
rustup target add x86_64-unknown-linux-gnu
npm run tauri build -- --target x86_64-unknown-linux-gnu
```

macOS 上编译 Windows 目标：

```bash
rustup target add x86_64-pc-windows-msvc
# 需安装 mingw-w64 交叉编译工具链
brew install mingw-w64
```

> 交叉编译可能遇到链接器错误，建议在各目标平台上原生构建。

## 替换应用图标

图标源文件：`src-tauri/icons/icon-source.png`（1024×1024，透明底）。

```bash
# 由源图生成全套图标（覆盖 src-tauri/icons/）
npx tauri icon src-tauri/icons/icon-source.png -o src-tauri/icons

# 关键：Cargo 增量构建不会感知 icons/ 变化，必须强制重跑构建脚本，
# 否则 exe 内嵌的仍是旧图标
touch src-tauri/build.rs        # Windows Git Bash；或 cargo clean -p deep-notifier

npm run tauri build
```

注意事项：

- **任务栏/托盘图标**来自运行时加载的 `icons/*.png`，替换后立即生效；**桌面快捷方式图标**来自 exe 内嵌资源（编译期由 `build.rs` 嵌入 `icon.ico`），两者来源不同，所以必须重新构建并重装。
- 重装后桌面图标仍显示旧图是 Windows 图标缓存问题，重启资源管理器（或执行 `ie4uinit.exe -ClearIconCache`）即可刷新。

## 配置说明

### Tauri 配置 (`src-tauri/tauri.conf.json`)

```jsonc
{
  "productName": "deepNotifier",
  "version": "0.1.0",
  "identifier": "com.deepnotifier.app",  // Bundle ID
  "build": {
    "beforeDevCommand": "npm run dev",     // dev 模式的前端启动命令
    "devUrl": "http://localhost:1420",     // dev 模式下加载的 URL
    "beforeBuildCommand": "npm run build", // 构建前执行
    "frontendDist": "../dist"              // 前端产物目录（相对 src-tauri）
  },
  "app": {
    "windows": [
      {
        "label": "main",
        "title": "deepNotifier",
        "width": 1000, "height": 630,
        "minWidth": 864, "minHeight": 500,
        "decorations": false  // 无原生标题栏，自定义实现
      },
      {
        "label": "marquee",
        "url": "src/marquee/marquee.html",
        "width": 1920, "height": 40,
        "decorations": false,
        "transparent": true,
        "alwaysOnTop": true,
        "skipTaskbar": true
      }
    ]
    // 注意：不要在 app 里配 "trayIcon"——配置文件会注册一个无菜单的托盘图标，
    // 与代码中 TrayIconBuilder（tray/menu.rs，id "main"）重复，导致托盘出现两个图标
  },
  "bundle": {
    "active": true,
    "targets": "all",           // 生成所有格式的安装包
    "icon": [                   // 各尺寸图标
      "icons/32x32.png",
      "icons/128x128.png",
      "icons/128x128@2x.png",
      "icons/icon.icns",
      "icons/icon.ico"
    ]
  }
}
```

### Vite 配置 (`vite.config.ts`)

- **Dev Server**: 端口 `1420`，strict port
- **路径别名**: `@` → `src/`
- **构建入口**: 双入口 — `index.html` (主窗口) + `src/marquee/marquee.html` (字幕窗口)
- **插件**: `@vitejs/plugin-react` + `@tailwindcss/vite`

### TypeScript 配置 (`tsconfig.json`)

- **Target**: ES2020
- **JSX**: `react-jsx` (自动导入)
- **Strict**: 全部开启 (`strict`, `noUnusedLocals`, `noUnusedParameters`)
- **路径映射**: `@/*` → `src/*`

## 版本发布流程

1. 更新版本号：
   - `package.json` → `version`
   - `src-tauri/Cargo.toml` → `version`
   - `src-tauri/tauri.conf.json` → `version`

2. 更新变更日志（如 `CHANGELOG.md`）

3. 提交并打 tag：
   ```bash
   git add -A && git commit -m "release v0.1.0"
   git tag v0.1.0
   git push origin main --tags
   ```

4. 构建安装包：
   ```bash
   npm run tauri build
   ```

5. 将 `src-tauri/target/release/bundle/` 下的安装包上传到 GitHub Releases
