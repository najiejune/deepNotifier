# deepNotifier 使用文档

[中文](使用文档.md) | [English](user-guide.md)

## 简介

deepNotifier 是一款面向开发者的桌面通知守护程序。它支持通过 Webhook（推送）和轮询（拉取）两种方式接收通知，并提供声音、滚动字幕、弹窗通知三种提醒方式。内置番茄钟和任务管理功能，帮助你在专注工作的同时不遗漏重要通知。

**支持平台**: Windows / macOS / Linux

---

## 安装与启动

### 安装

从 [Releases](https://github.com/najiejune/deepNotifier/releases) 页面下载对应平台的安装包：

| 平台 | 包格式 |
|------|--------|
| Windows | `.msi` / `.exe` |
| macOS | `.dmg` |
| Linux | `.deb` / `.rpm` / `.AppImage` |

### 启动

安装完成后，双击应用图标启动。应用会出现在系统托盘中，主窗口自动打开。

托盘菜单提供三个选项：
- **显示 deepNotifier** — 呼出主窗口
- **勿扰模式** — 快速开关勿扰模式
- **退出** — 完全退出应用

## 通知来源配置

### 方式一：Webhook（推送模式）

应用会启动一个本地 HTTP 服务器，接收来自 GitHub / GitLab / Bitbucket / 自定义 Webhook 事件。

#### 配置步骤

1. 进入 **设置 → Webhook**
2. 开启「启用 Webhook 服务器」
3. 设置端口号（默认 `3927`）
4. （可选）设置密钥用于签名验证
5. 选择需要接收的事件类型

#### GitHub Webhook 配置

在 GitHub 仓库的 **Settings → Webhooks** 中添加：

| 字段 | 值 |
|------|-----|
| Payload URL | `http://<你的IP>:3927/webhook/github` |
| Content type | `application/json` |
| Secret | 你在 deepNotifier 中设置的密钥 |
| Events | 按需选择（push, pull_request, issues 等） |

#### GitLab Webhook 配置

在 GitLab 项目的 **Settings → Webhooks** 中添加：

| 字段 | 值 |
|------|-----|
| URL | `http://<你的IP>:3927/webhook/gitlab` |
| Secret Token | 你在 deepNotifier 中设置的密钥 |
| Triggers | 按需选择（Push, Merge Request, Issues 等） |

#### Bitbucket Webhook 配置

在 Bitbucket 仓库的 **Settings → Webhooks** 中添加：

| 字段 | 值 |
|------|-----|
| URL | `http://<你的IP>:3927/webhook/bitbucket` |
| Secret | 你在 deepNotifier 中设置的密钥 |
| Events | 按需选择（repo:push, pullrequest:created 等） |

#### 自定义 Webhook

发送任意 JSON 到 `/webhook/custom`，通过点分隔路径提取标题和正文：

```bash
curl -X POST http://localhost:3927/webhook/custom \
  -H "Content-Type: application/json" \
  -d '{"title":"Deploy finished","body":"Build #42 passed","severity":"Info"}'
```

可在设置中自定义标题字段路径、正文字段路径和严重性等级。

> 如果 deepNotifier 部署在本地，需要使用内网穿透工具（如 ngrok）将本地端口暴露到公网。

### 方式二：轮询（拉取模式）

定期从指定的 HTTP 端点获取数据，通过内容哈希检测变化并发送通知。

#### 配置步骤

1. 进入 **设置 → 轮询**
2. 开启「启用轮询」
3. 点击「添加端点」
4. 填写端点信息：
   - **端点名称**：便于识别的名称
   - **URL**：接口地址
   - **间隔（秒）**：轮询频率
   - **请求方法**：GET 或 POST
   - **请求头**：自定义 HTTP 头
   - **POST 请求体**：请求内容（POST 方法时填写）

### 方式三：CLI Hook（AI 编程辅助工具）

向 CLI AI 辅助工具注入 hook 配置，让它们的事件推送到 deepNotifier，以普通通知（弹窗 / 滚动字幕 / 声音）的形式提醒你。

**支持的工具**:Claude Code、Codex、OpenCode、Gemini CLI、Kiro、CodeBuddy、Qoder、Kimi Code。

#### 工作原理

1. deepNotifier 向各 CLI 工具自己的配置文件写入 hook 条目（如 `~/.claude/settings.json`、`~/.codex/config.toml`)
2. CLI 内事件触发时，hook 将其 POST 到 `http://localhost:<端口>/hook/cli`
3. deepNotifier 收到后按你配置的提醒方式发出通知

#### 配置步骤

1. 进入 **设置 → CLI Hook**
2. 开启「启用 Hook 注入」
3. 设置 **Webhook 端口** — CLI 工具发送通知的端口
4. 在「CLI 工具列表」中查看检测到的工具（CLI ✓ = 工具本身已安装，Hook ✓ = hook 已注入），然后：
   - 点击单个工具的「安装」/「卸载」，或
   - 使用标题行右侧的「安装所有已启用」/「卸载全部」批量操作
5. 工具详情中可查看其**配置文件路径**和**已注入事件**

#### 事件通知

选择哪些 CLI 事件触发提醒，每个事件可单独开关声音 / 滚动字幕：

| 事件 | 触发时机 |
|------|----------|
| **停止** | CLI 一轮任务执行完毕时 |
| **通知** | CLI 发出通知、需要你关注时 |

#### 审批超时提醒

CLI 执行命令前会停下来等你批准（审批）。开启「审批超时提醒」并设置时长（秒）：审批等待超过此时长未处理时，deepNotifier 会提醒你。

> 点击弹窗卡片正文可聚焦到通知来源的终端窗口。

## 通知提醒方式

进入 **设置 → 通知** 进行配置：

### 声音提醒

收到通知时播放提示音。

- **声音文件**：内置 4 种提示音 — ping、chime、bell、alarm
- **音量**：0% ~ 100%

### 滚动字幕

收到通知时，屏幕顶部或底部出现滚动字幕条。

- 支持多显示器：每个屏幕独立显示
- 字幕条透明置顶，不阻挡鼠标操作
- 支持多轨道（弹幕式）：最多 3 条轨道同时滚动不同通知，字幕条高度随实际通知条数自适应
- 多条通知同时到达时自动排队轮播，不会互相覆盖；Critical 级别通知会立即抢占显示，播完后被中断的通知自动恢复
- 在 **设置 → 滚动字幕** 中可详细调整外观

### 弹窗通知

收到通知时，屏幕角落弹出应用内 Bitbucket 风格的弹窗卡片进行提醒，不再调用操作系统原生通知（Windows Toast / macOS / Linux libnotify）。

- 淡蓝色背景（`#DEEBFF`），半透明效果（透明度复用滚动字幕的透明度设置）
- 纯 SVG 等级图标：Info / Warning / Critical
- 显示在屏幕工作区角落，不会遮挡任务栏
- 多条通知自动排队依次显示，可点击 ✕ 手动关闭

弹窗显示时长按告警等级分别配置（**设置 → 通知**）：

| 级别 | 默认显示时长 |
|------|--------------|
| 信息（Info） | 10 秒 |
| 警告（Warning） | 10 秒 |
| 严重（Critical） | 0 秒 |

> 时长设为 0 表示不自动关闭，只能手动点击 ✕ 关闭。

## 勿扰模式

在指定时间段内抑制提醒。

### 手动开关

- 点击标题栏的「勿扰」按钮
- 或使用托盘菜单中的「勿扰模式」选项

### 定时计划

进入 **设置 → 勿扰模式** 添加计划：

1. 开启「启用勿扰模式」
2. 点击「添加计划」
3. 设置：
   - **名称**：如「午休」「晚间」
   - **时间范围**：开始时间 ~ 结束时间
   - **生效日期**：选择周一到周日

> 注意：勿扰模式开启后，声音、滚动字幕、弹窗三种提醒方式统一静音，通知仍会正常接收并存入历史记录。

## 滚动字幕设置

进入 **设置 → 滚动字幕**：

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| 预览 | 开启后实时预览字幕效果 | 关闭 |
| 预设搭配 | 5 种一键风格 | — |
| 位置 | 屏幕顶部或底部 | 顶部 |
| 持续时间 | 每条字幕在每个轨道的显示秒数 | 30 |
| 轨道数 | 同时滚动的最大字幕条数（1~3），空闲轨道不占屏幕空间 | 2 |
| 速度 | 滚动速度 | 100 |
| 高度 | 单个轨道高度（像素），字幕条总高 = 高度 × 当前通知条数 | 40 |
| 字体 | 9 种中英文字体可选 | System Sans |
| 字体大小 | 文字大小（像素） | 16 |
| 前置/后置图标 | 文字前后的 Emoji 装饰 | — |
| 背景颜色 | 支持透明（输入 `transparent`） | `#1e3a5f` |
| 文字颜色 | — | `#ffffff` |
| 背景透明度 | 0% ~ 100%，数值越大背景越透明，文字始终不透明；100% 时背景全透明 | 10% |

## 番茄钟设置

进入 **设置 → 番茄钟**，配置番茄工作法的全局参数。

番茄钟有 **工作 → 短休 → 工作 → 短休 → ... → 长休** 的阶段结构，自动循环。与任务关联，每完成一轮工作自动给当前任务记一个 🍅。

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| 工作时长 | 每次专注工作的分钟数 | 25 |
| 短休息时长 | 短休息的分钟数 | 1 |
| 长休息时长 | 长休息的分钟数 | 0（关闭长休） |
| 轮次 | 完成几轮短休后进入一次长休 | 4 |
| 提示音 | 计时结束时播放的声音 | chime |
| 自动开始休息 | 工作结束后自动开始休息倒计时 | 关闭 |
| 自动开始工作 | 休息结束后自动开始工作倒计时 | 关闭 |

> 长休息时长为 0 时跳过，仅进行工作→短休循环。开启两个自动开始后，番茄钟会连续自动运转，无需手动操作。

## 番茄钟与任务管理

进入 **待办任务** 页面：

### 任务管理

1. 在「任务列表」中输入任务内容，按回车或点击「添加任务」
2. 可设置截止日期
3. 支持筛选：全部 / 今天 / 本周
4. 点击任务可将其设为当前专注目标

### 配置番茄钟

点击任务旁的编辑按钮配置该任务的番茄钟参数（工作时长、短休时长、长休时长、轮次）。全局默认值在 **设置 → 番茄钟** 中统一配置。

### 操作按钮

| 按钮 | 功能 |
|------|------|
| ▶ 开始 | 开始计时 |
| ⏸ 暂停 | 暂停计时 |
| ▶ 继续 | 恢复计时 |
| ⏹ 结束 | 提前结束（不计入番茄数） |

如果中途点击「提前结束」，本次不计入番茄数。只有计时自然完成，才会为当前任务增加一个 🍅。

## 待办事项同步

进入 **设置 → 待办**：

### 拉取待办

从远程服务器定时拉取待办列表：

1. 开启「启用拉取」
2. 填写拉取 URL（返回格式：`{ "todos": [...] }`）
3. 设置拉取间隔（秒）
4. 选择请求方法（GET / POST）

### 推送待办

通过 HTTP 接受推送的待办事项：

1. 开启「启用推送服务器」
2. 设置推送端口（默认 `3928`）
3. 第三方通过 `POST http://localhost:3928/todos` 推送待办

## 配置存储

所有配置保存在系统应用配置目录中：

- **Windows**: `%APPDATA%/com.deepnotifier.app/`
- **macOS**: `~/Library/Application Support/com.deepnotifier.app/`

文件说明：

| 文件 | 格式 | 内容 |
|------|------|------|
| `config.toml` | TOML | 所有应用设置 |

## 常见问题

### Q: 如何彻底退出应用？

A: 右键系统托盘图标 → 点击「退出」。

### Q: 收到通知但没有声音？

A: 检查：1) 通知设置中声音是否开启；2) 勿扰模式是否启用；3) 系统音量是否正常。

### Q: 滚动字幕不显示？

A: 检查：1) 通知设置中字幕是否开启；2) 勿扰模式是否启用；3) 在滚动字幕设置中点击「预览」测试。

### Q: 多显示器下字幕只在主屏幕显示？

A: deepNotifier 会自动为每个显示器创建独立的字幕窗口。如果字幕未出现在副屏，请重启应用后重试。

### Q: Webhook 收不到通知？

A: 确保：1) Webhook 服务器已启用；2) 端口未被防火墙阻止；3) 如果 deepNotifier 在内网，需要配置内网穿透。

### Q: 如何重置所有设置？

A: 进入 **设置** → 点击右上角「重置」→ 点击「确认」。
